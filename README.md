Program 1: Singly Linked List in C++

Aim

To implement a singly linked list in C++ and perform various linked list operations.

Description

A singly linked list is a linear data structure in which each node contains data and a pointer to the next node. The last node points to "nullptr".

Algorithm

1. Define a node structure containing data and a pointer to the next node.
2. Initialize the head pointer to "nullptr".
3. Perform the linked list operations as required.
4. Display the linked list after performing the operations.

Time Complexity

- Insertion at the beginning: O(1)
- Insertion at the end: O(n)
- Deletion: Depends on the position and implementation.
- Traversal and display: O(n)
- Searching: O(n)

Space Complexity

- O(n), where n is the number of nodes in the linked list.

Test Cases

Test Case| Input/Operation| Expected Result
1| Insert elements 10, 20, 30| List contains 10 → 20 → 30
2| Display the list| All elements are displayed in order
3| Empty linked list| Display handles an empty list appropriately
